TÉCNICA DE DESARROLLO CLAVE

"Barco Estático, Mar que se Mueve"

Para que la Fase 3 de infiltración tenga físicas estables al 100%, el buque pesquero permanece quieto en coordenadas locales de Unity.

El NavMesh, los raycasts de los conos de visión y el CharacterController no sufren descalibración por cabeceo. El efecto de marea se logra desplazando el plano del océano y las coordenadas globales del shader.

Manual de Git y Reglas de Unity

Protocolo estricto para que los 3 desarrolladores trabajen en paralelo sin corromper escenas ni generar conflictos de fusión.

REGLAS DE ORO EN UNITY

Para Evitar Conflictos de Escena

  1. Nunca abran ni editen la misma escena a la vez: Cada integrante trabaja en su escena sandbox o mediante Prefabs modulares.
  2. Archivos .meta obligatorios: Todo nuevo script, audio o modelo debe comitearse junto a su archivo .meta correspondiente.
  3. Guardar antes de Git: En Unity presionar Ctrl + S y luego File -> Save Project.
  4. Git LFS activo: Modelos 3D (.fbx), texturas (.png, .psd) y audios pesados pasan por LFS automáticamente mediante .gitattributes.
CONVENCIÓN DE COMMITS

Formato de Mensajes

Utilizamos el estándar de Conventional Commits para que el historial sea claro:

feat(...): Nuevas mecánicas o scripts
art(...): Modelos 3D, shaders, texturas
ui(...): HUD, Canvas o menús
audio(...): Efectos de sonido y música
fix(...): Corrección de errores

Comandos de Terminal para Cada Integrante

bash · Flujo diario de trabajo
# 1. Cambiarse a su rama oficial al iniciar $ git checkout feature/alexander-ui-narrativa # (o diego-gameplay-ia / christopher-arte-audio) $ git pull origin develop # Traer lo nuevo integrado por los compañeros
# 2. Tras avanzar en Unity y guardar escena (Ctrl+S) $ git status # Revisar archivos cambiados $ git add . # Incluye scripts, prefabs y .meta $ git commit -m "feat(modulo): descripcion clara de lo realizado" $ git push origin feature/alexander-ui-narrativa
# 3. En GitHub.com abrir Pull Request hacia 'develop' para revisión

Guion Estructurado para la Exposición

Cómo presentar el proyecto ante el docente o jurado para demostrar visión comercial, calidad técnica y trabajo en equipo.

🎙️ Alexander Benites (Líder de Diseño & UX) — Introducción (60 segundos)

"Buenos días profesor. Nuestro proyecto se titula KAIROS: Sombras en Altamar. Es un videojuego de investigación 3D y sigilo táctico no violento desarrollado en Unity 6. Nos inspiramos en investigaciones periodísticas reales como The Outlaw Ocean Project y reportes de Global Fishing Watch, donde se documenta que más del 70% de la flota industrial en altamar apaga sus sistemas de rastreo para ocultar trata laboral y pesca ilegal. En KAIROS, el jugador no utiliza armas de fuego: encarna a un Inspector Civil de Derechos Humanos cuya misión es recolectar evidencias físicas con valor judicial, selladas digitalmente con criptografía SHA-256 para cerrar puertos a las flotas ilegales."

🎨 Alexander Benites — Diseño, UI/UX y Sistema de Confianza

"Desde la dirección de diseño estructuré el bucle en 4 fases híbridas: desde la pantalla satelital hasta el juicio penal. En la interfaz diseñé el HUD del sonar, el panel de rastreo orbital y el sistema de diálogos con las víctimas basado en un Medidor Dinámico de Confianza (0 a 100%) y consentimiento informado, garantizando que el juego no revictimice a los pescadores rescatados."

⚙️ Diego Tornero — Programación, Físicas e Inteligencia Artificial

"En la parte técnica de Unity y C#, implementé el CharacterController en tercera persona con modo sigilo y detección de escaleras, la física de flotabilidad y propulsión de la lancha de intercepción, y la máquina de estados de la Inteligencia Artificial de los guardias (Patrulla, Sospecha y Alerta) con conos de visión afectados por clima nocturno y lluvia."

🌊 Christopher Veliz — Arte 3D, Entorno Marítimo y Audio

"En la dirección de arte construí la estructura modular 3D del buque pesquero Hai Feng 77, los materiales PBR de óxido ferroso y acero salino, el shader de oleaje nocturno y la vista térmica en Shader Graph. Además integré el paisaje sonoro inmersivo con crujidos de cuadernas, ecos de hidrófono y viento de tormenta marina."
